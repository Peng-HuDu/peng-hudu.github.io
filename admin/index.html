私有资料库编辑与发布

这是公开网站上的编辑器界面。连接 GitHub 后，浏览器会从你的私有 academic-profile 仓库读取资料；保存时只写回该私有仓库，再由 GitHub Actions 更新公开网页。完整资料 JSON 不会放在此公开网站。细粒度令牌只需授权 academic-profile 仓库和 Contents: Read and write，仅在当前标签页内存中使用，不会保存或发送到聊天。
